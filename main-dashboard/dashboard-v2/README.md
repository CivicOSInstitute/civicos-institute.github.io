# CivicOS Dashboard v2 (MacBook)

This folder contains the Dashboard v2 spec, wireframe blocks, and implementation checklist.

## Files
- `DASHBOARD_V2_SPEC.md` — information architecture, sections, thresholds, and UX rules
- `WIREFRAME_BLOCKS.md` — desktop + mobile wireframe block map
- `DATA_SCHEMA.md` — normalized data contract + source mapping
- `IMPLEMENTATION_CHECKLIST.md` — build order and acceptance criteria

## Intended mount point
Integrate into `main-dashboard` as a dedicated route (e.g., `/v2`) with this folder as source-of-truth docs.
