# CivicOS AI Pre-Course Bootcamp (10 Days)

## Goal
Prepare learners to confidently engage modern deep learning topics through a practical, governance-aware foundation.

## Outcomes by Day 10
- Read and modify basic Python ML/DL scripts
- Understand train/validation/test, overfitting, and evaluation metrics
- Build and train a basic Keras model end-to-end
- Understand embeddings, transformers, and finetuning at a practical level
- Map AI implementation choices to accountability and governance tradeoffs

## Daily Plan (90–120 min/day)

### Day 1 — Python Refresh
Syntax, functions, lists/dicts, file IO, CSV/JSON parsing.

### Day 2 — NumPy + Pandas
Arrays, DataFrames, cleaning, feature prep.

### Day 3 — Statistics + Metrics
Distributions, leakage, precision/recall/F1, risk-aware metric selection.

### Day 4 — Baseline Models
Train/val/test split, simple baseline classifier, error analysis.

### Day 5 — Neural Network Essentials
Perceptron, activations, loss, gradient descent, backprop intuition.

### Day 6 — Keras Workflow
Build/compile/fit/evaluate, callbacks, early stopping, experiment tracking.

### Day 7 — Computer Vision Basics
CNN intuition, transfer learning, practical model comparison.

### Day 8 — NLP Fundamentals
Tokenization, bag-of-words, embeddings, baseline text classification.

### Day 9 — Transformers + LLM Concepts
Attention intuition, transformer stack, prompt vs RAG vs finetuning choices.

### Day 10 — CivicOS Integration
Produce a 2-page readiness memo with:
- model choice
- governance controls
- evaluation/monitoring plan
- human oversight checkpoints

## CivicOS Non-Negotiables
1. What public decision is impacted?
2. How are outcomes audited?
3. Where is human override mandatory?
4. What failure mode most harms public trust?
