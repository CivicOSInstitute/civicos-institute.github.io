# Skill Writing Patterns

## Trigger description formula
Use this in frontmatter description:

"<What it does>. Use when <specific trigger contexts>."

## Strong input/output definition
- Inputs: required + optional
- Outputs: fixed structure
- Errors: explicit reason + next step

## Edge-case checklist
- Missing required fields
- Empty data
- Permission failures
- Tool unavailable
- Non-deterministic output handling
