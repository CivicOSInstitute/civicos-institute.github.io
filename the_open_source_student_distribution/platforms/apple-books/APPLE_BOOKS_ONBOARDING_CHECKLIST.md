# Apple Books Onboarding Checklist — The Open Source Student

## 1) Account Setup (manual, owner-required)
- [ ] Sign in to Apple Books Connect: https://authors.apple.com/
- [ ] Complete agreements, tax, and banking setup
- [ ] Verify publisher profile and contact details

## 2) Book Listing Package
- [ ] Title: The Open Source Student
- [ ] Subtitle: Practical AI & Open-Source Skills for Real-World Execution
- [ ] Author: Nick Cerbone
- [ ] Description / marketing text
- [ ] Categories and BISAC mapping
- [ ] Language, publication date, regions

## 3) Files
- [ ] EPUB upload (Apple Books compliant)
- [ ] Cover upload (front cover image)
- [ ] Apple Books Preview validation pass

## 4) Pricing
- [ ] Base price and territory pricing grid
- [ ] Availability windows

## 5) Launch
- [ ] Submit for review
- [ ] Confirm storefront availability
- [ ] Save Apple Books ID in dashboard metadata

## Required Manual Inputs
- Apple account owner acceptance of legal agreements
- Tax and banking confirmations
- Regional rights decisions
