# Amazon KDP Onboarding Checklist — The Open Source Student

## 1) Account Setup (manual, owner-required)
- [ ] Sign in/create account: https://kdp.amazon.com
- [ ] Complete publisher profile (legal name, address, phone)
- [ ] Add tax interview details (W-9/W-8BEN)
- [ ] Add royalty payout bank account
- [ ] Confirm marketplace and payment preferences

## 2) Book Listing Package
- [ ] Title: The Open Source Student
- [ ] Subtitle: Practical AI & Open-Source Skills for Real-World Execution
- [ ] Author: Nick Cerbone
- [ ] Description (long-form sales copy)
- [ ] 7 backend keywords
- [ ] 2 categories (Education/Technology variants)
- [ ] Age/grade ranges (if applicable)

## 3) Files
- [ ] Manuscript upload (EPUB for Kindle reflow OR KPF)
- [ ] Cover upload (Kindle cover JPG/TIFF)
- [ ] Previewer pass + TOC verification

## 4) Pricing/Rights
- [ ] Territories: Worldwide (or selected)
- [ ] Royalty plan: 70%/35% as applicable
- [ ] List price set for each marketplace

## 5) Launch
- [ ] Publish Kindle eBook
- [ ] (Optional) Set pre-order or KDP Select enrollment
- [ ] Save ASIN to dashboard metadata

## Required Manual Inputs
- KDP account owner approval
- Tax identity confirmations
- Banking details
- Final legal publishing rights confirmation
