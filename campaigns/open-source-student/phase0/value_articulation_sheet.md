# Value Articulation Sheet — External Legibility

## Core question
Why $179 instead of a free PDF or low-cost technical title?

## Externally legible answer
Because this is a complete, civic-context capability curriculum, not a standalone reference text.

## Specific value claims
1. **Synthesis:** unified learning path across licensing, local AI workflows, version control, open data, and civic application
2. **Civic framing:** built for institutional/public-interest use cases, not generic software-only contexts
3. **Pedagogical structure:** sequenced for self-directed learning and classroom companion adoption
4. **Depth:** practitioner-grade scope in one artifact

## Funding architecture
**Book revenue funds free civic materials.**

## Objection handling
- “There are free alternatives.” → Free resources are fragmented; this is integrated and implementation-ready.
- “$179 is high for a book.” → This is positioned as curriculum infrastructure, not recreational reading.
- “Is this paywalled knowledge?” → Paid edition funds ongoing free public outputs.
